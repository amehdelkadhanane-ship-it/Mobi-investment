CONTIX PHONE'S AND GADGETS — Pro Admin + AI-ready Store
This package upgrades the CONTIX storefront with a much more powerful admin interface.
Included:
Add, edit and delete products
Multiple product image uploads with previews
Product price, old price, stock, category and description controls
Orders and customer dashboard
AI customer-support interface with human handover
Admin AI assistant area
Marketing/ads setup area for TikTok, Facebook/Instagram, X and analytics
Paystack public-key settings
Store/email settings
No public phone number in the storefront
IMPORTANT: This is a front-end foundation/prototype. Browser storage is used for demonstration, so it is not yet a shared production database. For a real public store, connect the API functions to a secure backend/database. Paystack secret keys and AI API keys must never be placed in browser JavaScript.
Production architecture: Website -> secure backend/database -> products/orders/customers Checkout -> Paystack -> server verification/webhook -> paid order Customer AI -> secure AI backend -> store database/knowledge Marketing -> official TikTok/Meta/X ad accounts and tracking
